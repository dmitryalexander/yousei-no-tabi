# Component and asset notices

The component source trees retain their own license files, including
`libultraship/LICENSE`, `torch/LICENSE`, and notices in vendored libraries.
Original copyright notices embedded in code and fonts are retained.

`fonts/` includes the SIL OFL 1.1 notices from the Google Fonts upstream
directories for Montserrat, Inconsolata, Noto Sans JP, and Press Start 2P.
Sources: https://github.com/google/fonts/tree/main/ofl

The optional legacy Fipps font was removed from this edition because its
redistribution notice was not present in the upstream checkout. The remaining
overlay fonts provide the normal menu/counter functionality.

Lighting environments and procedural data have separate provenance in
`docs/ASSET_PROVENANCE.md`. Poly Haven photographic inputs are CC0.

There is no new project-wide license grant over the upstream game code or
Nintendo content. Game assets must be obtained and extracted by the user.
